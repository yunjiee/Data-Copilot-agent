# TheLook 智慧電商助理解析系統

歡迎使用 **TheLook 電商數據與內部知識助理**！👋

本系統整合了數據庫與內部知識庫，能夠根據您的問題自動選擇合適的工具來為您解答。您可以隨時詢問我關於電商營運數據或是公司內部規範的問題。

### 🎯 我可以幫您完成以下任務：

#### 1. 📊 查詢營收與商品績效 (數據分析)
我會自動撰寫並執行 BigQuery SQL，幫您撈取資料庫中的量化數據。
**您可以這樣問：**
> * 「幫我查詢上個月總營收是多少？」
> * 「列出目前銷售績效最好的前 5 名商品。」
> * 「請問退貨率最高的商品類別是哪一個？」
> * 「幫我計算今年 Q1 相比去年 Q1 的營收成長率。」

#### 2. 📚 檢索公司內部規範與流程 (知識庫檢索)
我會透過 RAG 技術，從公司的向量知識庫 (Qdrant) 中為您找出精確的質化資訊與規定。
**您可以這樣問：**
> * 「請問公司內部的退貨率要怎麼計算？」
> * 「請問『商品退貨率』與『訂單退貨率』可以混用嗎？」
> * 「公司內部報表對於各項營收指標的定義是什麼？」
