# TheLook 智慧電商助理解析系統

歡迎使用 **TheLook 電商數據與內部知識助理**！👋

本系統整合了數據庫與內部知識庫，能夠根據您的問題自動選擇合適的工具來為您解答。您可以隨時詢問我關於電商營運數據或是公司內部規範的問題。

### 🎯 我可以幫您完成以下任務：

#### 1. 📊 查詢營收與商品績效 (數據分析)
我會自動撰寫並執行 BigQuery SQL，幫您撈取資料庫中的量化數據。
**您可以這樣問：**
> * 「幫我查詢上個月總營收是多少？」
> * 「列出目前銷售績效最好的前 5 名商品。」
> * 「請問退貨率最高的商品類別是哪一個？」
> * 「幫我計算今年 Q1 相比去年 Q1 的營收成長率。」

#### 2. 📚 檢索公司內部規範與流程 (知識庫檢索)
我會透過 RAG 技術，從公司的向量知識庫 (Qdrant) 中為您找出精確的質化資訊與規定。
**您可以這樣問：**
> * 「請問公司內部的退貨率要怎麼計算？」
> * 「請問『商品退貨率』與『訂單退貨率』可以混用嗎？」
> * 「公司內部報表對於各項營收指標的定義是什麼？」

#### 3. 📈 自動化行銷簡報生成 (PPTX Presentation Skill)
系統能將量化數據洞察與知識庫規範融合，自動生成專業的行銷與營運策略投影片 (.pptx)。
**您可以這樣問：**
> * 「請利用剛剛查詢的 Q1 銷售數據與指標定義，製作一份 5 頁的行銷複盤簡報。」
> * 「幫我將熱銷 Top 5 商品與退貨率分析輸出為主管匯報投影片。」

---

### 💾 本地數據快取與循環利用 (Cache & Reuse)
為了加速簡報迭代與除錯，系統支援**中間結果保存機制**：
* 當前執行的 BigQuery 分析結果與 RAG 知識片段會自動保存於 `mas_output/cache/`。
* 簡報生成 Agent 啟動時會**優先檢查本地快取**，若已有可用數據將直接載入，無須重複呼叫 BigQuery 與向量資料庫，大幅節省 Token 與測試時間！
